## Основные модули

`src/db/backend/db.py` содержит общий интерфейс базы данных:

- `DataBase` определяет основные методы работы с артистами и альбомами.
- `MemoryDataBase` реализует этот интерфейс.

`src/db/backend/record.py` содержит классы записей:

- `ArtistRecord` описывает одну запись артиста.
- `AlbumRecord` описывает одну запись альбома.

`src/db/backend/table.py` содержит классы таблиц:

- `ArtistTable` хранит артистов и проверяет операции с артистами.
- `AlbumTable` хранит альбомы и проверяет связь альбома с существующим артистом.

`src/db/backend/memorydb.py` содержит базу данных в оперативной памяти:

- `MemoryDataBase` хранит таблицы артистов и альбомов.
- Методы базы вызывают методы соответствующих таблиц.
- При удалении артиста проверяется, что у него нет альбомов.

`src/db/backend/errors.py` содержит пользовательские исключения:

- `DuplicateIdError`
- `RecordNotFoundError`
- `ValidationError`
- `ForeignKeyError`
- `ProtectedRecordError`

Все исключения наследуются от `ValueError`, поэтому текстовый интерфейс может обрабатывать их одинаково.

`src/db/tui.py` содержит класс `ConsoleApplication`, который отвечает за меню, ввод данных и вывод результатов.

## Функциональность

Программа поддерживает:

- добавление, поиск, обновление и удаление артистов;
- добавление, поиск, обновление и удаление альбомов;
- фильтрацию артистов по `id`, псевдониму и жанру;
- фильтрацию альбомов по `id`, названию, артисту, году выпуска и лейблу;
- проверку уникальности `id`;
- проверку обязательных полей;
- проверку года выпуска альбома;
- запрет удаления артиста, если у него есть альбомы.

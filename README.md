## Основные модули

`src/db/backend/db.py` содержит общий интерфейс `DataBase`.

Через этот интерфейс реализованы две базы данных:

- `MemoryDataBase` из `memory.py` наследуется от `DataBase` и хранит данные в оперативной памяти;
- `FileDataBase` из `file.py` наследуется от `DataBase` и сохраняет данные в JSON.

`src/db/backend/record.py` содержит классы записей:

- `ArtistRecord` описывает артиста;
- `AlbumRecord` описывает альбом.

`src/db/backend/table.py` содержит классы таблиц:

- `ArtistTable` хранит артистов;
- `AlbumTable` хранит альбомы и проверяет связь с артистами.

`src/db/backend/errors.py` содержит пользовательские исключения:

- `DuplicateIdError`;
- `RecordNotFoundError`;
- `ValidationError`;
- `ForeignKeyError`;
- `ProtectedRecordError`;
- `FileDataBaseError`.

`src/db/tui.py` содержит класс `ConsoleApplication` и выбор типа базы данных.

## Возможности программы

- добавление, поиск, изменение и удаление артистов;
- добавление, поиск, изменение и удаление альбомов;
- фильтрация записей по полям;
- проверка уникальности идентификаторов;
- проверка обязательных полей и года выпуска;
- запрет удаления артиста, если у него есть альбомы;
- сохранение файловой базы после каждой операции;
- загрузка сохранённых данных при повторном запуске;
- обработка повреждённых файлов и неправильной структуры данных.

## Формат файловой базы

Файловая база создаёт один файл `database.json`. В нём находятся две таблицы, их структура и записи.

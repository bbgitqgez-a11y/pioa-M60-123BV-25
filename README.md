## Структура проекта

### `main.py`
Точка входа. Запускает текстовый интерфейс программы.

### `tui.py`
Модуль с текстовым интерфейсом пользователя.
Отвечает за:
- вывод меню
- получение данных от пользователя
- вызов функций работы с базой данных
- вывод результатов на экран

**Вспомогательные функции ввода:**
- `_ask_int()` — считывает целое число, повторяет запрос при ошибке
- `_ask_optional_int()` — считывает целое число или возвращает `None` при пустом вводе
- `_ask_nonempty_string()` — считывает непустую строку, повторяет запрос при ошибке

**Функции вывода:**
- `_show_artists()` — выводит список артистов в виде таблицы
- `_show_albums()` — выводит список альбомов в виде таблицы

**Функции работы с артистами:**
- `_create_artist()` — диалог добавления артиста
- `_search_artists()` — диалог поиска артистов по фильтрам
- `_modify_artist()` — диалог обновления данных артиста
- `_drop_artist()` — диалог удаления артиста

**Функции работы с альбомами:**
- `_create_album()` — диалог добавления альбома
- `_search_albums()` — диалог поиска альбомов по фильтрам
- `_modify_album()` — диалог обновления данных альбома
- `_drop_album()` — диалог удаления альбома

**Меню:**
- `_artists_menu()` — меню операций с артистами
- `_albums_menu()` — меню операций с альбомами
- `run()` — главная функция запуска, отображает основное меню

### `backend/memory.py`
Модуль хранения данных в оперативной памяти.

**Типы**
- `ArtistEntry = tuple[int, str, str]` — запись артиста: `(id, псевдоним, основной_жанр)`
- `AlbumEntry = tuple[int, str, int, int, str]` — запись альбома: `(id, название, id_артиста, год_выпуска, лейбл)`

---

**Таблицы**
- `Artists: list[ArtistEntry]` — хранилище артистов
- `Albums: list[AlbumEntry]` — хранилище альбомов

---

**Функции для работы с артистами**
- `add_artist(artist_id, nickname, main_genre)` — создаёт артиста и добавляет в `Artists`
- `find_artists(artist_id, nickname, main_genre)` — возвращает артистов по заданным фильтрам; без фильтров — всю таблицу
- `edit_artist(artist_id, nickname, main_genre)` — обновляет данные артиста по `id`
- `remove_artist(artist_id)` — удаляет артиста по `id`; запрещает удаление, если у артиста есть альбомы

---

**Функции для работы с альбомами**
- `add_album(album_id, title, artist_id, release_year, label)` — создаёт альбом и добавляет в `Albums`
- `find_albums(album_id, title, artist_id, release_year, label)` — возвращает альбомы по заданным фильтрам; без фильтров — всю таблицу
- `edit_album(album_id, title, artist_id, year, label)` — обновляет данные альбома по `id`
- `remove_album(album_id)` — удаляет альбом по `id`

---

**Вспомогательные функции**
- `_artist_exists(artist_id)` — возвращает `True`, если артист с указанным `id` существует
